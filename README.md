# DisasterGuard

## Project Description

DisasterGuard is a disaster management application designed to help people and rescue teams during emergency situations. It provides disaster alerts, identifies high-risk areas, allows users to send SOS requests, and helps rescue teams prioritize areas where immediate assistance is needed.

## Proposed Solution

DisasterGuard provides a centralized platform for disaster response. The application collects emergency information, identifies areas with higher risk, and helps rescue teams focus on locations that require immediate attention.

## Features

* 🚨 Disaster alerts and emergency information
* 📍 Identification of high-risk areas
* 🆘 SOS emergency request
* 🚑 Helps prioritize rescue operations
* 👥 Supports communication between users and rescue teams
* 📱 Simple and user-friendly interface
* 🔥 Firebase-based data management

## Objective

The main objective of DisasterGuard is to reduce response time during disasters and help rescue teams provide assistance to people in the most critical areas first.

## Technologies Used

* Flutter
* Dart
* Firebase
* Firebase Authentication
* Firebase Realtime Database
* Android Studio
* Visual Studio Code

## How to Run

1. Install Flutter and set up the Flutter development environment.
2. Clone or download this repository.
3. Open the project in Visual Studio Code or Android Studio.
4. Run:

```bash
flutter pub get
```

5. Connect an Android device/emulator.
6. Run:

```bash
flutter run
```
